# qa_python
## Sprint_5
### Это проект для тестирования сайта `https://stellarburgers.nomoreparties.site/`
1. **test_login.py** - проверка входа: по кнопке «Войти в аккаунт» на главной; через кнопку «Личный кабинет»; через кнопку в форме регистрации; через кнопку в форме восстановления пароля.
2. **test_logout.py** - проверка выхода из аккаунта: по кнопке «Выйти» в личном кабинете.
3. **test_personal_account.py** - проверка перехода в личный кабинет: переход по клику на «Личный кабинет».
4. **test_redirect_from_personaL_account.py** - проверка перехода из личного кабинета: по клику на «Конструктор»; по клику на логотип Stellar Burgers.
5. **test_registration.py** - проверка регистрации: успешная регистрация; ошибка некорректного пароля.
6. **test_tabs_switch.py** - проверка перехода к разделам: «Булки»; «Соусы»; «Начинки». 
7. **conftest.py** - фикстуры: драйвер; генератор email; генератор password.
8. **data.py** - зарегистрированный пользователь.
9. **locators.py** - локаторы страниц.# Sprint_5
10. **urls.py** - URLs используемые в проекте
